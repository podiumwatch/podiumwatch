How to view
Open index.html in a browser.

How to edit
1. Replace the sample ranking and story links in index.html.
2. Replace the cropped logo in the assets folder with the original Podium Watch logo when available.
3. Update the Instagram, YouTube, and email links.
4. Upload the folder to GitHub and deploy it with Vercel.

This version uses plain HTML, CSS, and JavaScript. It does not require Node.js or any packages.
