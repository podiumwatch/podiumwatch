## Finding: most "different" timing companies are the same underlying platform

Live-verified 2026 08 05, prompted by a real request to research Can't Stop Timing Co. (Piqua, Ohio): its cross country and track results are timed onto FinishTiming's TrackScoreboard platform (confirmed JS-rendered, see above). Separately, `live.seotiming.com`, `live.pierretiming.com`, `results.timingfirst.com`, and `results.championshiptiming.org` -- four domains this project already tracks as distinct "timing company" providers -- were fetched directly and found to return **byte-for-byte identical pages** (49,697 bytes each), titled "AthleticLIVE" and loading their JavaScript from `livestatic.athletic.net`. These are not four independent platforms; they are the same white-labeled Athletic.net live-results product running under four different branded domain names. This is consistent with, and helps explain, why this project already scopes all four to "Approved external handoff" rather than direct crawling.

The practical implication: essentially every modern, professionally-run Ohio high school timing company product is a JavaScript single-page application, whether built in-house (TrackScoreboard) or licensed from Athletic.net (the AthleticLIVE white-label). None of them can be read by a plain HTTP fetch, for the same reason MileSplit Live and Athletic.net's own site cannot -- the result data does not exist in the server's response at all, only in the browser after JavaScript runs. Baumspage remains the one real exception found so far, precisely because it is not a timing company's product -- it is a long-running, hand-maintained HTML archive of meets and linked files, built before (and never migrated to) this generation of live-results tooling.

## Access policy

The crawler uses public HTTPS addresses only, validates DNS and every redirect, limits size, time, retries, depth, pages, and redirects, and never bypasses login, CAPTCHA, or access controls. Dynamic or restricted providers always have file upload and pasted text fallbacks.

## Evidence standard

Live public inspection, controlled integration fixtures, and database workflow tests are recorded separately. A page being publicly visible does not mean direct bulk extraction is permanently guaranteed.
