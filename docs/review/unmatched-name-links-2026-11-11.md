# Unmatched name links: review list

Checked 2026-11-11 against the live database. These names on the site have no link because they didn't match exactly one page. Nothing here was changed: no aliases were added. Possible fixes, your call for each:

- **No school with this exact name**: an alias in src/data/awards-2026-school-aliases.json mapping the label to the right school (only if you can confirm which school), or fix the name in the source data.
- **Matches 2 or more schools**: the label is ambiguous (for example "Green"). Use the city in the source ("Green (Uniontown)"), or an alias once you confirm the school.
- **School found, but no published team page**: publish (or create) that team page.
- **No profile with this name / at this school**: the athlete has no public profile, or the profile is at a different school (or has none). Fix the profile or leave it.

### Perrysburg (not fixed, needs your OK)

Perrysburg is in the Ohio schools list once, as **"Perrysburg High School"** (Perrysburg, OHSAA 1248, id d965a8ba-e044-4a63-be6c-2130e0b98f68). Its team page exists and is published (perrysburg-high-school-perrysburg-1248) with the name "Perrysburg". The link index matches on the Ohio schools list name, so the label "Perrysburg" finds nothing: it's a spelling difference, not a missing row or a duplicate. Almost every other row in that list leaves off "High School". Two possible fixes: rename the Ohio schools row to "Perrysburg" (a data change), or add a "Perrysburg" alias. Not done.
