# Podium Watch official reference files

This folder stores original official reference documents used by the statewide data foundation.

## Included files

1. `2026-27-boys-cross-country-divisions.pdf`

   Supplied OHSAA boys cross country school assignments for the 2026 and 2027 and 2027 and 2028 classification cycles. The document contains 556 schools, OHSAA school IDs, cities, athletic districts, boys base enrollment, current assignments, and previous assignments.

2. `2026-track-regional-sites-and-representation.pdf`

   Supplied OHSAA track and field regional site document updated April 3, 2026. It contains 16 regional entries, dates, times, locations, contacts, and representation notes. The source is marked subject to change.

## Source handling rules

1. Keep the original PDF files unchanged.
2. Store parsed data in clearly named JSON files.
3. Record the source title and last verified date with every imported record.
4. Do not apply boys cross country assignments to girls cross country or track and field.
5. Treat the track regional document as subject to change.
6. Use the Statewide Data Center preview before importing or updating database records.
