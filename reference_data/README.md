# Podium Watch reference data

Place original official PDFs, spreadsheets, CSV files, and source notes in this folder.

Recommended structure:

```text
reference_data
reference_data\official
reference_data\rankings
reference_data\regional
reference_data\processed
reference_data\archive
```

Rules:

1. Keep original files unchanged.
2. Use descriptive filenames.
3. Record season and date.
4. Put transformed files in `processed`.
5. Do not treat projections as official facts.
6. Keep source notes beside processed data.
